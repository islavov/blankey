# Locking, workspaces and settings {#more}

## Lock and unlock

**Lock** makes the data unreadable for you and for any assistant. Unlock with the master password or Touch ID. **Forgot password?** asks for the recovery key.

![Lock](shot:workspace-lock)
![Unlock](shot:workspace-unlock)

## Workspaces {#workspaces}

A workspace is a separate set of data with its own master password, for example your own papers and the office's. They are changed on the lock screen.

![The workspace list on the lock screen](shot:workspace-workspaces)
![New workspace…](shot:workspace-new-workspace)

## Back up, restore, delete

**Settings** (the cog), **Local backup…** saves the workspace as one encrypted file. **Restore from backup…** on the lock screen brings it back as a workspace of its own, with the password it was backed up with.

![Local backup…](shot:workspace-backup)
![Restore from backup…](shot:workspace-restore)

> Delete workspace… removes the open workspace from this computer for good.

![Delete workspace…](shot:workspace-delete-workspace)

## Blankey Online in Settings

The account, the connection, **Account and billing**, which documents Blankey can read, and the web assistants you allowed.

![Settings: Blankey Online](shot:online-settings)

## Web assistants {#web-assistants}

Add the **Connector URL** to a web assistant such as claude.ai as a custom connector. Blankey asks you before it lets one in. **Revoke** cuts one off.

![Revoke](shot:online-revoke)
